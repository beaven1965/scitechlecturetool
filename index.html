🧰 Assessment Tools

🧠 How to make a HOTS testQuick guide · free

HOTS (Higher-Order Thinking Skills) items make learners analyze, evaluate and create — not just remember. Follow these steps:

  1. Start with a TOS. List the competencies, how many days you taught each, and how many items each should get. Use the TOS maker below.
  2. Spread the thinking levels. A common DepEd mix is Easy 60% (Remember, Understand) · Average 30% (Apply, Analyze) · Difficult 10% (Evaluate, Create). For a HOTS test, aim higher, e.g. 30% · 40% · 30%.
  3. Give a situation first. HOTS items start with a short scenario, data table, graph, picture, quote or case from the learners' real life — then ask them to think about it.
  4. Ask "why, how, which is better, what if". Avoid questions answerable by copying one line from the book.
  5. Write strong choices. All options should look possible; wrong options should come from common mistakes. Avoid "all of the above" and tricky negatives ("which is NOT…").
  6. Include a few open-ended items (explain, justify, design) scored with a short rubric.
  7. Check alignment. Every item matches its competency and level in the TOS. Prepare the answer key and rubric before giving the test.
Question starters by level
  • Remember What is…? List… Name… When did…?
  • Understand Explain in your own words… What is the main idea…? Give an example of…
  • Apply How would you use… to solve…? What would happen if you followed… in this situation?
  • HOTS · Analyze What is the cause of…? How are… and… different? Which data supports…? What pattern do you see?
  • HOTS · Evaluate Which solution is best and why? Do you agree with…? Justify. What is the weakness of this argument?
  • HOTS · Create Design a… Propose a plan to… What would you change so that…? Make a new rule/model for…
